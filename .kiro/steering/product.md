# Product Steering — NECRO-BBS 1989 (Kiroween 2026: Resurrection)

## Mission
Resurrect the classic **1989 Dial-Up ANSI Bulletin Board System (BBS)**—acoustic modem handshakes, phosphor CRT terminals, FidoNet-style message echo boards, ZMODEM file transfers, and ASCII Door Games—inside a zero-backend, 60fps modern 2026 web application.

## Target Category
- **Primary**: Kiroween 2026 — **Resurrection** (reviving dead 1980s dial-up BBS technology with modern Web Audio synthesis, responsive dual-mode keyboard/pointer UX, and portable JSON state bridging).
- **Visual Polish**: Haunted CRT phosphor themes (`Phosphor Green P1`, `Amber P3`, `Spectral Violet`), CRT scanline toggle, and live acoustic modem status LEDs (`OH`, `CD`, `TX`, `RX`).

## Core User Experience Principles
1. **Instant Carrier Connect**: Users can experience an authentic procedural Web Audio 2400-baud modem handshake (`ATDT 555-1989` → `CONNECT 2400`) or skip straight to instant 2026 fiber speed with 1 click.
2. **Dual Input Accessibility**: Every BBS module supports authentic single-key terminal hotkeys (`[M]`, `[D]`, `[F]`, `[S]`, `[Q]`, `WASD`/Arrows) AND clickable modern HUD buttons so any visitor or judge can explore effortlessly.
3. **Zero External Asset Fragility**: All audio (DTMF tones, V.22bis carrier screech, key clicks, ghost encounter SFX) is procedurally generated via Web Audio API; all ANSI art is deterministic UTF-8 box-drawing text.
